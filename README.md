# Who Checks the Agent?

**Ethics in agentic AI data analytics.** Slides for a talk by Hong Qin (Old Dominion University), October 8, 2026.

AI agents such as Claude Code and Codex now read data, write and run code, submit cluster jobs and edit manuscripts. This talk looks at four kinds of failure in agentic data analysis (hallucination, hidden actions, misalignment and supply-chain risk) through public incidents and anonymized research cases, and ends with habits students can start using right away.
